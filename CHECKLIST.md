# Checklist de revisao

1. O codigo faz o que o pull request diz que faz?
2. Da para entender os nomes das variaveis e das funcoes?
3. Tem senha ou token escrito direto no codigo?
4. Sobrou console.log ou codigo comentado?
5. Quebrou alguma coisa que ja estava funcionando?
6. Se der erro, aparece alguma mensagem?
